# CCTL 数据流基础模块

`spsc_record_ring.hpp` 提供预分配的单生产者、单消费者定长记录环形缓冲区。
初始化完成后，生产与消费路径均不加锁、不分配内存。缓冲区满时 `try_push()`
立即返回 `false`，由调用方决定丢弃、重试或故障策略。

该模块不依赖线程、文件系统和具体仿真拓扑。CCTL 主机 CSP 使用它连接仿真线程
和文件输出线程，其他高速采集或日志场景也可以通过 `gmp_src_mgr` 的
`cctl|dsa` 模块复用。

容量参数以字节给出，实际记录容量为 `byte_capacity / record_size`，因此 32 MB
配置不会因为记录对齐而越界。`size()` 和 `capacity()` 可用于进度监控，但不能
把该结构用于多生产者或多消费者场景。
