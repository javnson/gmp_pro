# GMP C29x SysConfig peripheral guide

The maintained C29x peripheral guide is [README_CN.md](README_CN.md). It covers
the GMP lifecycle, ePWM period/compare/dead-band/trip configuration, ePWM-triggered
ADC sampling, eQEP, GPIO, UART Data Link, SPI, I2C, MCAN, and FSI. The examples are
cross-referenced to TI F29H85x SDK 1.02.01.00.

Use CCS 21 or newer and select the `GMP-Core-C29x` Product. The
`f29h850tu9_lp` directory provides the validated C29 compiler/SysConfig baseline
and a UART Data Link plus LED example.
