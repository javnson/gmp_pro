# MCS_ACM_NT SIL 调试记录

日期：2026-08-09 至 2026-08-10  
模型：`project/simulate/MCS_STD_ACM_MODEL.slx`

## 验收规则

- 角度统一为周标幺，比较角度时先包络到 `[-0.5, 0.5)`。
- 电流跟踪正常不等于磁场定向正确；必须同时检查真实转子磁链角。
- 无感交接必须检查交接前独立捕获、交接后同步速度保持和失锁回退。
- 未通过的阶段不得作为下一阶段硬件上电依据。

## 结构修订

1. 将 `imfoc_core` 改为与 `mc_foc_core_t` 同级的独立 ACIM 电流内核，移除内嵌 `foc_core`、位置计算器和磁链观测器。
2. 电流内核输入明确为磁链角/同步速度；编码器轴角/机械速度只进入机械环和有感位置计算器。
3. 有感 `acim_pos_calc` 使用 `tau_r=Lr/Rr`、精确 ZOH 磁化电流滤波、滑差和同步角积分。
4. 无感 `acim_fo` 对照 TI ACIFE/ACISE，实现电流模型、定子磁链参考、梯形反电势积分、转子磁链反算和滑差；角度由 PLL 提取，不使用直接 `atan2`。
5. 审核共享 `ato_pll` 的 PMSM ESMO、FO 和 HFI 调用方，统一周标幺相位误差和 `2*pi` 比例。

## 已定位的问题与修复

### 基础控制链

- `clear` 清除了预设引用，导致使能后指令丢失：修改为只清动态状态，保留用户参考。
- 模型初始滑差设置使转轴并非静止：初始条件改为从静止起动。
- 模型电机参考系改为 stationary，明确控制器与模型的 αβ 映射。
- Level 1 固定电压在零频率会过磁：改为随频率斜坡变化的 V/f。
- 有感位置计算器滑差使用实测 `iq`，避免把未实现的电流参考当成实际转矩电流。

### 标幺与角度

- `omega_base=2*pi*f_base`，速度为电气角速度标幺。
- 角积分系数为 `omega_base*Ts/(2*pi)`，输出为周标幺。
- ATO 的输入是周标幺相位误差；归一化叉积得到弧度小信号后除以 `2*pi`。
- SIL 中理论 PWM 重构系数为 `0.5*udc_pu*vab_command`。早期 `1/3` 只在 0.05 s 单点吻合，中高速磁链幅值不足，已撤销。

### 无感交接实验

1. 每周期强制 PLL 到 I/F 角会让交接条件失去意义，已改为低速强制、捕获区自由运行。
2. 捕获阶段电流模型使用电流环实际磁场角，PLL 候选角独立用于相位鉴别。
3. 试验过 0.5/5/20 Hz 复合校正和 1/5 Hz 泄漏积分；高带宽能建立初值，但交接后出现电流模型自锁，低带宽又不足以抑制积分偏置。
4. 当前采用捕获/运行增益调度和 5 Hz 泄漏积分作为继续研究基线，但 2 s SIL 仍未满足交接后速度保持要求。
5. 已增加后交接速度一致性监测。失败后 `acim_sensorless_fault_latched=1`，磁场角和同步速度回到 I/F，直到重新清零。
